# LobsterPlus 实施方案（一次到位版）

为有道 LobsterAI（龙虾）桌面客户端做家族式多账号管理器，架构蓝本复刻 RaccoonPlus/TraePlus（Tauri 2 + Rust + 无框架前端），签到与 API 接入逻辑移植 youdaocheckin/youdaoAPI。

## 已确认决策

| 决策点 | 结论 |
|---|---|
| 多账号形态 | 切换式（串行），非并行多开 |
| 交付节奏 | 一次到位：切换+签到+API 代理单版本全交付 |
| 切换粒度 | 目录级快照（manifest 清单式部分交换） |
| API 路线 | 固定端口稳定器 + 转发 LobsterAI 轮换本地代理 |
| 代理能力 | OpenAI + Anthropic 双协议 + 一键注册进 CC-Switch |
| 签到调度 | GUI 启动补签+每小时循环；CLI 子命令可挂 Windows 计划任务 |
| 技术栈 | Tauri 2 + Rust（GNU 工具链）+ 原生 JS 前端 |

## 模块一：多账号切换 + 对话保留

**账号快照 = manifest 清单式部分目录交换**（对话库无账号字段，这是唯一安全路径）：

**manifest 包含**（账号私有状态）：`lobsterai.sqlite(+wal/shm)`、`DIPS*`、`openclaw\state\`（openclaw.json+bak、gateway-token、gateway-port.json、agents\ 整树含 openclaw-agent.sqlite 与 import-archive）、`openclaw\.openclaw\exec-approvals.json`、`openclaw\plugin-skills\`、`SKILLs\`、`Partitions\`、`Local Storage\`、`Session Storage\`、`Network\`、`Shared Dictionary\`、`Shared Storage\`、`Preferences`、`Local State`
**排除**（可重建/静态）：Cache\*、Code Cache\*、GPUCache\*、Dawn*Cache\*、blob_storage\、logs\、updates\（298MB）、runtimes\、cowork\、openclaw\{bin,logs,cache,media,.compile-cache}\、lockfile

**切换流程** `store.rs::switch_to`：
1. 目标==当前 → 仅 sync_back 保鲜
2. LobsterAI 运行中 → 优雅关闭（taskkill 不带 /F，10s 超时后 /F，等全部进程退出——6 个 Electron 进程）
3. ProxyLock 跨进程锁
4. **sync_back**：live 的 manifest 路径回写当前账号快照（对话、token 全量保鲜）
5. **auto_preserve**：live 登录未入库 → 自动收编为新账号
6. **first_backup**：首次切换前把 manifest 子集 zip 到 backups\
7. 交换：live manifest 路径 → 移入源账号快照；目标快照 → 拷回 live（临时文件+rename 原子替换）
8. **读回校验**：解 live kv 的 auth_user.id == 目标账号 id，失败自动从备份回滚
9. 释放锁，可选自动重启 LobsterAI（settings 开关，默认开）

**账号身份**：kv `auth_user`（id/yid/nickname/avatarUrl）为主键识别，auth_ref（refreshToken SHA-256）兜底。
**账号库**：`~\.lobster-plus\accounts\<uuid>.json` = 元数据（明文）+ 加密 auth blob（enc:v1：accessToken/refreshToken/keyfrom/installation_uuid/userId 供签到独立续期）+ last_checkin 状态 + 快照目录指针。
**首个账号来源**：手动"捕获当前登录"按钮 + 首次切换时 auto_preserve。

**实现期验证项**：①切号后 diff `~\.openclaw\identity\device-auth.json` 是否随账号变（是→加入 manifest）；②refresh token 是否单次轮换（决定活跃账号签到策略）。

## 模块二：多账号每日自动签到

Rust 移植 youdaocheckin 已逆向的三步接口（ureq，服务端 `https://lobsterai-server.youdao.com`）：
1. `GET /api/client-activities/slot?placement=desktop_sidebar&clientVersion=…&containerApiVersion=2&platform=win32` → activityCode + configRevision（code 51102=登录失效）
2. `GET /api/client-activities/{code}/context?configRevision={rev}` → claimedToday 预检
3. `POST /api/client-activities/{code}/actions/check_in`，body `{"configRevision", "idempotencyKey": uuid4, "payload":{}}`；code 0 成功（读 creditsGranted/claimedDays/claimedCredits），51104 已签

**token 策略**：非活跃账号用账号库加密 blob 独立续期（`POST /api/auth/refresh`，辅助字段随快照收编），续期成功回写 blob + 该账号快照 sqlite 的 kv 行；**活跃账号**优先读 live sqlite 新鲜 token，仅在 app 未运行且过期时才自行续期写回（规避与客户端续期竞态）。
**调度**：GUI 启动 catchup_once（补今天未签账号）+ 每 3600s 循环 + 单账号 1h 节流（TraePlus 模式）；CLI `checkin --all` 供 `schtasks` 每日 09:00 调用，另有 `install-schedule`/`uninstall-schedule` 子命令。结果写 account.json 并在 GUI 账号卡片展示（今日+N 积分/累计天数）。

## 模块三：API 稳定代理 + CC-Switch 注册

**形态**：内嵌 Python 代理 `lobster_proxy.py`（fork raccoon_proxy.py 的 Anthropic↔OpenAI 双向转换、SSE 发射器、工具调用互转——已实战验证），Rust proxy.rs 负责释放/启停/健康探测；Python 发现三级：PATH → LobsterAI 自带 `runtimes\python-win\python.exe` → py.exe。

**稳定器**（替换原 AuthManager）：候选端口取自 `openclaw\state\agents\main\agent\models.json` 与 `openclaw\state\openclaw.json` 两处 baseUrl（实测会互相过期，如 1316 vs 实际 2880）+ 各自 apiKey，TCP 探活 + `GET /v1/models` 验证选活；缓存结果，请求失败自动重探测。全挂 → 503 "LobsterAI 未运行"。**上游端口/key 轮换对 CC-Switch 彻底透明**。

**端点**（监听 127.0.0.1:19260，可配）：`POST /v1/chat/completions`（纯透传）、`GET /v1/models`（透传）、`POST /v1/messages`（Anthropic→OpenAI 转换后发上游，复用 raccoon 转换层）、`/v1/messages/count_tokens`、`/health`。模型映射：上游存在的模型名直通，claude-* 前缀按 proxy-config.json 映射（默认 opus→glm-5.3、sonnet/haiku→deepseek-flash），兜底 default_model。代理鉴权：settings 首次运行生成固定 key，仅监听 127.0.0.1。

**一键注册 CC-Switch**（register.rs，rusqlite 移植 add_provider.py）：备份 `%USERPROFILE%\.cc-switch\cc-switch.db` → upsert provider "LobsterPlus(本地)"（apiFormat=native、ANTHROPIC_BASE_URL=http://127.0.0.1:19260、AUTH_TOKEN=代理 key、模型映射）→ 还原写入前激活项。GUI 按钮 + CLI 子命令。

## CLI 全功能镜像

`list / capture / switch <id> [--force] / rename / delete / checkin [--all|--id] / proxy start|stop|status / register-ccswitch / install-schedule / uninstall-schedule / doctor [--json]`。doctor 一键诊断：数据目录/安装路径/账号数/活跃身份/上游探测/代理健康/cc-switch 注册状态/Python 发现。JSON 输出走 account_public 过滤，无任何密钥。

## 安全与测试

- 红线：绝不写 live lobsterai.sqlite（除非 app 已退出且为 token 续期回写）；切换必过读回校验，失败自动回滚；删账号需确认且 backups 保留
- 单元测试：manifest 拷贝引擎（临时目录）、kvdb（临时 sqlite）、zcrypto、checkin 判定逻辑
- 沙箱：`LOBSTER_PLUS_HOME` 重定向账号库；`switch --dry-run` 列出将交换的文件
- **实机 E2E 清单**（一次到位验收）：捕获→切 A↔B 往返→两边对话记录完好→全账号签到→proxy 双协议 curl 验证（含 SSE）→CC-Switch 注册后 Claude Code 实际对话→schtasks CLI 签到。**需要你提供一个可登录的第二账号做切换 E2E**
